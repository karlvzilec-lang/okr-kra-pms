# okr-kra-pms web

Next.js frontend for the [okr-kra-pms](../README.md) performance-management PoC — one screen, the employee KRA + OKR review summary. See the root README for setup, environment variables, and the design system this page follows.

```bash
npm install
cp .env.example .env.local   # fill in from `npx supabase status` (run from the repo root)
npm run dev
```
